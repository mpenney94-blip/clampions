# League notes for the written columns

Claude reads this file every time it writes a recap, preview or rivalry column. Add to it whenever there's league lore or
real-life news worth a mention. Columns should bring these up now and then, when they fit, not every week.

## Traditions
- Duck hunt: the team that loses the losers bracket (the toilet bowl: lose every game there and you finish last) has to
  dress up as a duck while everyone else in the league shoots him with paintballs. Any team out of the playoff race is a
  duck-hunt candidate, and anyone near the bottom of the standings is fair game for duck jokes.

## Style
- Every manager in the league is a guy: refer to a manager or team as "he" when a pronoun fits.
- Puns are always welcome, especially on team names, player names and the duck hunt.
